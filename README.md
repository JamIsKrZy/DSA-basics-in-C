# Purpose
Making for fun :D

## How to Execute GPS Program 
1.) Go to folder
```terminal
cd JamIsKrZy
```

2.) build the project
```
make GPS
```

3.) Run Program file
```
./runGPS
```

## How to Compile and Execute Iterator
The directory of the terminal must be in the workspace dir

1.) Enter in terminal
```
make -f Iterator/makefile build
```

2.) Execute binary
```
./iter
```
